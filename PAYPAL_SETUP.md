# PayPal Integration Setup

This document provides instructions on how to set up PayPal integration for the InseparableFX platform.

## Getting PayPal API Credentials

1. Go to the [PayPal Developer Dashboard](https://developer.paypal.com/dashboard/)
2. Log in with your PayPal account or create a new account if you don't have one
3. Navigate to "My Apps & Credentials" in the dashboard
4. Select "REST API apps" and click "Create App"
5. Enter a name for your app (e.g., "InseparableFX")
6. Select "Merchant" as the app type
7. Click "Create App"
8. Once created, you'll see your Client ID and Secret
